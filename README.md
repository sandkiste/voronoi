Der Voneroi Generator hat nur einen einfachen Zweck. Den Deckel von meinem Arduino Gehäuse mit einem Vonoroi Muster aufzubrechen damit das mit der Kühlung besser klappt. 

Der Voronoi Generator verwendet die JavaScript Bibliothek d3-delaunay (https://github.com/d3/d3-delaunay).

Die Webapp kannst du auf guileless-sherbet-c8f193.netlify.app live testen.
